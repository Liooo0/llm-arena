# 模型选型结论表 · 2026-08

> 数据来源：`reports/benchmark-2026-08.md`（3 轮对战、63 题、181 次真实调用）

| 场景 | 推荐模型 | 原因 |
|---|---|---|
| 日常问答 | Flash | 成本低、延迟低，质量与 Pro 打平 |
| 结构化抽取 | Flash | 足够稳定（100% 成功率） |
| 复杂推理 | Pro | 单答深度略优 |
| Coding | Pro / Flash 均可 | 对战无碾压，按成本选 |
| 高吞吐任务 | Flash | 成本优势（约 Pro 的 1/6） |
| 高价值复杂任务 | Pro / qwen3.7-max | 能力优先 |

**关键数据（2026-08-19 轮，10 题 × 2 模型，同题同 prompt）：**

| 指标 | Flash | Pro | 差距 |
|---|---|---|---|
| 平均耗时 | 24.2s | 38.2s | Flash 快 58% |
| 平均 token | 1385 | 2233 | Pro 多 61% |
| 单题成本（估） | ~0.004 元 | ~0.023 元 | Flash 省约 6 倍 |
| 质量 | 与 Pro 打平 | 与 Flash 打平 | 无碾压 |

**为什么 Flash 是生产默认（一句话）：**
同一道题，Flash 和 Pro 质量打平，但 Flash 快 58%、token 省 61%、成本约 1/6。
